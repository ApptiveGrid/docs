ApptiveScript-Funktionen ​

Vollständige Liste der Funktionen, die in einem Ausdruck zur Verfügung stehen — in Formelspalten, in der bedingten Sichtbarkeit von Blöcken, in Flow-Bedingungen und in Filtern.

Diese Seite ist zum Nachschlagen gedacht. Wenn Sie zum ersten Mal einen Ausdruck schreiben, fangen Sie bei Was ist ApptiveScript an.

So lesen Sie die Tabellen ​

Ein Ausdruck ist immer Wert, Punkt, Funktion:

fieldValue('preis').multiplyBy(1.19)

Links vom Punkt steht ein Wert, rechts eine Funktion aus der Tabelle seines Typs. Das Ergebnis hat wieder einen Typ — und darauf können Sie erneut eine Funktion anwenden:

fieldValue('nachname').concat(fieldValue('vorname'), ', ').isNotEmpty()
SpalteBedeutung
FunktionDer Name, so wie er geschrieben wird. Einträge mit vorangestelltem Punkt und ohne Klammern — etwa .email — sind Eigenschaften und brauchen keine Argumente.
ArgumenteWas in die Klammern gehört, in dieser Reihenfolge: name: Typ.
ErgebnisDer Typ des Ergebnisses. Er entscheidet, welche Tabelle für den nächsten Punkt gilt. Any heißt: ein Wert, dessen Typ erst beim Auswerten feststeht — etwa bei einem Wert aus JSON-Daten.

Funktionsnamen sind englisch und bleiben es auch in der deutschen Oberfläche. Groß- und Kleinschreibung ist verbindlich.

Der Typ steht im Editor

Der Dialog Einen Ausdruck bearbeiten zeigt über dem Beispielergebnis den ermittelten Typ an — Typ: String, Typ: Number und so weiter. Damit finden Sie die Tabelle, die für den nächsten Punkt gilt. Der Reiter Search im Editor führt ohnehin nur die Funktionen des gerade ermittelten Typs.

Mit oder ohne geschweifte Klammern ​

Wo Sie schreibenSchreibweise
Formeleditor, Sichtbarkeit, erweiterte Flow-Logiknur der Ausdruck: fieldValue('preis').multiplyBy(1.19)
normales Textfeld in einem Flow-Schrittin Klammern: Ihre Rechnung über {{ fieldValue('betrag') }} Euro

Ein Ausdruck ohne Klammern behält seinen Typ. Sobald Sie ihn in einen Text einbauen, ist das Ergebnis Text — und lässt sich nicht mehr weiterrechnen.

Werte in den Ausdruck holen ​

Womit ein Ausdruck anfängt, hängt davon ab, wo er steht:

EinstiegBedeutungVerwendet in
fieldValue('<Feld-Id>')ein Feld des aktuellen EintragsFormelspalten, Filter
formValues.get('<Key>')ein Eingabewert der Seitebedingte Sichtbarkeit
step('<Schritt-Id>').outputdas Ergebnis eines früheren Flow-SchrittsFlows
today()das heutige Datumüberall
now()der aktuelle Zeitpunktüberall
true, falsefeste Wahrheitswerteüberall

Feld-Ids und Schritt-Ids tippt niemand von Hand — der Editor fügt sie über den Picker ein. Der Key eines Eingabeblocks ist dagegen selbst gewählt; er steht unter Keys verwalten.

Ids sind keine Namen

fieldValue('…') verweist auf die Id einer Spalte, nicht auf ihren Namen. Das ist gewollt: Eine Formel überlebt damit das Umbenennen der Spalte. Umgekehrt heißt es aber auch, dass sich ein Ausdruck nicht durch Lesen der Feldnamen prüfen lässt.

Leere Werte ​

Ein Feld, das nicht gefüllt ist, liefert keinen Fehler, sondern einen leeren Wert. Zwei Funktionen fangen das ab:

FunktionWirkung
ifUndefined(<Ersatzwert>)setzt einen Ersatzwert ein, wenn der Wert fehlt
isEmpty() / isNotEmpty()prüft, ob ein Wert fehlt
fieldValue('spitzname').ifUndefined('unbekannt')

ifUndefined gibt es auf jedem Typ, isEmpty() und isNotEmpty() auf fast jedem — bei Zahl, allgemein nicht. Die Tabellen weiter unten sagen es genau.

Aus einer Liste einen Wert holen ​

Einige Funktionen liefern eine Liste statt eines einzelnen Wertes — etwa match(), das alle Treffer eines Suchmusters sammelt. An einen einzelnen Eintrag kommen Sie mit at():

'a,b,c'.match('[a-z]').at(1)

Das ergibt a — der erste Eintrag hat die Nummer 1, nicht 0. Wie viele es sind, sagt size().

Eine Liste ist kein anzeigbarer Wert

Eine Formelspalte muss auf einem einzelnen Wert enden. Hört der Ausdruck bei der Liste auf, kann die Spalte ihn nicht darstellen — hängen Sie at() an.

Erzeugt aus ApptiveScript 0.3.302 mit npm run apptivescript:reference.

Auf jedem Typ verfügbar ​

Diese Funktionen gibt es unabhängig davon, was links vom Punkt steht. In den Tabellen der einzelnen Typen sind sie deshalb nicht wiederholt.
