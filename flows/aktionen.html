Aktionen ​

Aktionen sind die Schritte, die ein Flow ausführt. Sie liegen im Editor im Reiter Aktionen mit dem Hinweis Wähle eine Aktion aus, um deinen Flow zu erweitern.

Ein Flow kann beliebig viele Aktionen enthalten, hintereinander oder verzweigt.

Mit „Pro" gekennzeichnete Aktionen

Einige Aktionen tragen im Editor die Kennzeichnung Pro und stehen nur im höchsten Tarif zur Verfügung. Sie sind unten entsprechend markiert.

Mit eigenen Daten arbeiten ​

Eintrag erstellen ​

Erstellt einen neuen Eintrag

Legt einen Eintrag in einem Grid an. Die Feldwerte setzen Sie fest oder aus vorherigen Schritten.

Geeignet für: Daten aus einem Formular in ein zweites Grid spiegeln, Protokolleinträge schreiben, Aufgaben erzeugen.

Kann den eigenen Flow erneut auslösen

Schreibt eine Aktion in dasselbe Grid, auf das der Auslöser Neuer Eintrag hört, startet der Flow sich selbst — immer wieder. Schreiben Sie in ein anderes Grid oder wählen Sie einen präziseren Auslöser.

Eintrag aktualisieren ​

Einen Eintrag mit neuen Werten aktualisieren

Ändert Felder eines bestehenden Eintrags — üblicherweise des Eintrags aus dem Auslöser.

Geeignet für: Status setzen, Bearbeitungszeitpunkt festhalten, berechnete Ergebnisse zurückschreiben.

Alle Einträge laden ​

Lade alle Einträge eines Grids

Holt die Einträge eines Grids als Liste in den Flow.

Geeignet für: Sammelauswertungen, Serienmails, regelmäßige Berichte.

Fast immer mit „Parallel" kombiniert

Eine Liste allein bringt wenig. Erst der Helfer Parallel führt die folgenden Schritte für jeden Eintrag einzeln aus.

Nach außen kommunizieren ​

E-Mail ​

Eine Mail senden

Empfänger, Betreff und Text lassen sich frei zusammensetzen — mit festen Texten und Werten aus vorherigen Schritten.

Geeignet für: Bestätigungen, Benachrichtigungen, Erinnerungen, Weiterleitungen.

HTTP-Anfrage ​

Eine beliebige HTTP-Anfrage senden

Die allgemeine Aktion für alles, wofür es keine fertige Integration gibt. Sie geben URL, Methode, Kopfzeilen und Inhalt selbst an.

Geeignet für: eigene Systeme, Werkzeuge mit offener Schnittstelle, Automatisierungsdienste.

Slack · MS Teams · Firebase Cloud Messaging ​

Fertige Aktionen zum Versand einer Nachricht in den jeweiligen Dienst.

Hubspot ​

Legt einen Kontakt im Hubspot-CRM an.

Magenta Business SMS · Verify · Verify Check — Pro ​

SMS versenden sowie Telefonnummern per SMS-Code bestätigen. Verify verschickt den Code, Verify Check prüft die Eingabe.

Geeignet für: Zwei-Faktor-Bestätigung, Terminerinnerungen per SMS.

Diese Dienste verlangen eigene Zugangsdaten

Für Slack, MS Teams, Firebase, Hubspot und Magenta Business brauchen Sie ein eigenes Konto beim jeweiligen Anbieter. Die Zugangsdaten tragen Sie im Flow-Schritt selbst ein — bei Slack und MS Teams eine Webhook-URL, bei Firebase einen API-Schlüssel, bei Hubspot ein API-Token, bei Magenta Schlüssel und Geheimnis.

Besorgen Sie diese, bevor Sie den Flow bauen. → Integrationen im Überblick

Dateien und Inhalte erzeugen ​

QR Code ​

Erstellt einen QR Code

Erzeugt einen QR-Code aus einem übergebenen Inhalt.

PDF zu Text — Pro ​

PDF in Text umwandeln

Liest den Textinhalt eines PDF aus.

Geeignet für: eingehende Rechnungen oder Formulare maschinell auswerten.

URL zu PDF — Pro ​

Webseite in PDF umwandeln

Erzeugt aus einer Webadresse ein PDF.

Belege und Bestätigungen erzeugen

In Kombination mit einer veröffentlichten Seite lassen sich damit Bestätigungen und Belege als PDF erzeugen: Seite mit den Eintragsdaten aufrufen, in PDF wandeln, per E-Mail versenden.

CSV-Datei importieren ​

Importiert eine CSV-Datei

Liest eine CSV-Datei von einer Adresse ein und stellt die Zeilen als Liste bereit.

Sprache zu Text — Pro ​

Audio in Text umwandeln

Wandelt eine Audioaufnahme in Text um — etwa aus dem Block Sprachaufnahme eines Formulars.

Document Analyzer — Pro ​

Wertet Dokumente mit KI aus.

Kalendereintrag ​

Erzeugt einen Kalendereintrag aus Titel, Beschreibung und Zeitangaben.

DATEV Lohn & Gehalt — Pro ​

Erstellt eine DATEV Import-Datei

Erzeugt eine Importdatei für DATEV Lohn & Gehalt.

Zugangsdaten erforderlich

Diese Aktion verlangt Zugangsschlüssel und Passwort Ihres DATEV-Zugangs. Halten Sie diese bereit und behandeln Sie sie vertraulich.

Mit KI arbeiten ​

OpenAI — Pro ​

Schickt einen Prompt an ChatGPT und liefert die Antwort zurück.

Eingaben: Prompt und optional Zusätzliche Anweisungen.

Geeignet für: Texte zusammenfassen, Rückmeldungen einordnen, Antwortentwürfe erzeugen.

Kein eigener OpenAI-Vertrag nötig

Anders als bei den übrigen Integrationen brauchen Sie hier keinen eigenen Zugang und keinen API-Schlüssel. Der Schritt läuft über ApptiveGrid und ist einsatzbereit, sobald Ihr Tarif ihn enthält.

Prüfen Sie, welche Daten Sie übergeben

Der Inhalt eines Prompts verlässt ApptiveGrid und wird an einen externen Dienst gesendet. Übergeben Sie keine personenbezogenen oder vertraulichen Daten ohne vorherige datenschutzrechtliche Prüfung.

JavaScript ​

Führt JavaScript code aus

Führt eigenen Code aus, wenn keine der fertigen Aktionen passt. Der Editor bietet:

  • Eine Vorlage: const data = input … return data
  • Mit KI generieren — Beschreiben Sie in Worten, was der Code tun soll
  • Vorherige Flow-Daten an KI senden — gibt der KI das Ergebnis des vorherigen Schritts als Kontext
  • Vorherige Code-Version wiederherstellen

Schlägt die Erzeugung fehl, meldet der Editor JavaScript konnte nicht generiert werden.

Der Schritt ist frei, die KI-Erzeugung nicht

JavaScript ausführen steht in jedem Tarif zur Verfügung — Sie können also immer eigenen Code schreiben.

Tarifgebunden ist nur Mit KI generieren. Ohne diese Funktion tippen Sie den Code selbst, was für die meisten Umformungen ohnehin schneller geht als eine Beschreibung in Worten.

Mit Menschen interagieren ​

Seite anzeigen ​

Zeigt eine Seite zur Nutzerinteraktion an

Hält den Flow an und zeigt einer Person eine Seite. Nach dem Absenden läuft der Flow weiter.

Geeignet für: Genehmigungen, Rückfragen, mehrstufige Erfassung.

Nicht mit dem gleichnamigen Auslöser verwechseln

Es gibt auch einen Auslöser namens Seite anzeigen. Der startet einen Flow, diese Aktion unterbricht ihn. Siehe Trigger.

Fehlt einem Schritt die zugewiesene Seite, erscheint:

Für diesen Schritt ist keine eigene UI hinterlegt. Falls du eine UI benötigst, kannst du sie im Flow Editor hinzufügen.

Link zu Seite erstellen ​

Erstellt einen Link zu einer Seite im Flow

Erzeugt einen Link auf den aktuellen Durchlauf. Diesen Link können Sie per E-Mail verschicken, damit jemand später an dieser Stelle weitermacht.

Der Weg zu asynchronen Prozessen

Seite anzeigen setzt voraus, dass jemand gerade da ist. Link zu Seite erstellen in Kombination mit E-Mail funktioniert auch, wenn die Person erst morgen Zeit hat: Sie bekommt den Link zugeschickt und öffnet ihn, wann es passt.

Vorausgefüllter Formularlink ​

Aktualisiert einen Eintrag

Erzeugt einen Link auf ein Formular, das den Eintrag bereits vorausgefüllt zur Bearbeitung öffnet.

Geeignet für: Korrekturaufforderungen, Zu- und Absagen, Datenpflege durch Externe.

Nichts Passendes gefunden? ​

Der Editor verweist selbst darauf: Nichts passendes gefunden? mit der Möglichkeit, eine Anfrage zu stellen.

Vorher lohnt der Blick auf HTTP-Anfrage — damit lassen sich die meisten Dienste anbinden, die eine offene Schnittstelle haben.
