Berechnete Felder ​

Drei Spaltentypen berechnen ihren Wert selbst, statt ihn von Hand zu erfassen:

TypWoraus
Wert übernehmeneinem verknüpften Eintrag
Summe berechnenmehreren verknüpften Einträgen
Formeleinem Ausdruck

Alle drei sind schreibgeschützt und stehen nicht in Formularen zur Verfügung.

Zwei setzen eine Verknüpfung voraus

Wert übernehmen und Summe berechnen funktionieren nur, wenn im Grid bereits eine Verknüpfung besteht. Legen Sie diese zuerst an — siehe Grids verknüpfen.

Wert übernehmen ​

Holt einen Wert aus einem verknüpften Eintrag in das aktuelle Grid.

Beispiel: Das Grid „Anmeldungen" verweist über Eintrag verknüpfen auf „Veranstaltungen". Mit Wert übernehmen holen Sie das Veranstaltungsdatum direkt in die Anmeldung.

Einstellungen:

EinstellungBedeutung
VerknüpfungsfeldWelche Verknüpfungsspalte verwendet wird
ZielfeldWelches Feld aus dem verknüpften Eintrag geholt wird

Der Wert aktualisiert sich automatisch. Ändert sich das Datum in „Veranstaltungen", ändert es sich in allen Anmeldungen mit.

Statt zu kopieren, übernehmen

Der häufigste Anfängerfehler ist, wiederkehrende Werte in beide Grids zu schreiben. Damit laufen die Daten früher oder später auseinander. Wert übernehmen hält sie automatisch synchron — die Angabe existiert weiterhin nur an einer Stelle.

Übernommene Werte sind filterbar

Ein übernommenes Datum lässt sich filtern und sortieren wie ein normales Feld. Damit bauen Sie eine Ansicht „Anmeldungen für kommende Veranstaltungen", ohne das Datum doppelt zu pflegen.

Summe berechnen ​

Summiert ein numerisches Feld über alle verknüpften Einträge.

Beispiel: Das Grid „Rechnungen" verweist über Mehrere Einträge verknüpfen auf „Positionen". Mit Summe berechnen steht der Gesamtbetrag automatisch in der Rechnung.

Einstellungen:

EinstellungBedeutung
VerknüpfungsfeldEine Spalte vom Typ Mehrere Einträge verknüpfen
ZielfeldDas zu summierende numerische Feld

Braucht die Mehrfach-Verknüpfung

Mit Eintrag verknüpfen funktioniert dieser Typ nicht — es gibt nichts zu summieren. Sie brauchen Mehrere Einträge verknüpfen.

Typische Anwendungen: Rechnungssummen, Projektaufwände, Bestellwerte, Teilnehmerzahlen.

Formel ​

Berechnet einen Wert aus einem Ausdruck.

Einstellungen:

EinstellungBedeutung
AusdruckDie Berechnung, in ApptiveScript
ErgebnistypWelchen Typ das Ergebnis hat

Der Editor (Einen Ausdruck bearbeiten) zeigt ein Beispielergebnis und den ermittelten Typ, sodass Sie die Formel prüfen können, bevor Sie sie übernehmen.

Sprachreferenz fehlt noch

Der vollständige Funktionsumfang von ApptiveScript ist an dieser Stelle noch nicht dokumentiert. Nutzen Sie das Beispielergebnis im Editor, um eine Formel schrittweise zu entwickeln.

Die wichtigste Einschränkung ​

Berechnete Felder lösen keine Flows aus

Felder vom Typ Wert übernehmen, Summe berechnen und Formel können im Flow-Auslöser Eintrag wurde geändert nicht als auslösendes Feld gewählt werden. Sie tauchen dort gar nicht erst auf.

Ändert sich also eine berechnete Summe, startet kein Flow.

Der Ausweg: Reagieren Sie auf das Feld, das die Berechnung verursacht hat.

Statt „wenn sich die Rechnungssumme ändert" bauen Sie den Flow auf „wenn eine Position hinzukommt" — also einen Auslöser Neuer Eintrag im Grid „Positionen".

Dasselbe gilt für Erstellt am: auch dieses Feld steht als Bedingung nicht zur Verfügung.

Welcher Typ für welche Aufgabe ​

Sie wollen …Typ
Eine Angabe aus einem verknüpften Eintrag anzeigenWert übernehmen
Beträge über mehrere verknüpfte Einträge summierenSumme berechnen
Werte innerhalb eines Eintrags verrechnenFormel
Auf eine Änderung reagierenFlow — berechnete Felder lösen nicht aus
Kennzahlen über eine ganze Ansicht bildenGruppierung mit Aggregat

Berechnung schlägt Automatisierung

Für abgeleitete Werte ist ein berechnetes Feld fast immer besser als ein Flow: Es aktualisiert sich sofort, verbraucht keinen Flow aus Ihrem Tarif und kann nicht fehlschlagen.

Ein Flow lohnt sich, wenn etwas passieren soll — nicht, wenn etwas nur angezeigt werden soll.
